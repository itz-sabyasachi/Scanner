SHIELD VERIFY SCANNER
1. Copy jsQR.min.js into this folder (next to index.html):
   https://cdn.jsdelivr.net/npm/jsqr@1.4.0/dist/jsQR.js  (save as jsQR.min.js)
2. Open index.html with VS Code Live Server, or run:  python -m http.server 8000
   then visit http://localhost:8000
3. Hard-refresh with Ctrl+Shift+R.
